## ◈ The vision

OPTIMETA is built for players who want Minecraft to feel smoother without losing what makes it Minecraft.

A performance-focused pack with a simple philosophy:

> **Performance first. Vanilla feel always.**

## ⚡ What we're aiming for

| Focus | Goal |
|---|---|
| 🚀 **Performance** | Improve frame rates where the selected mods and hardware allow |
| 🌊 **Smoothness** | Reduce stuttering and improve frame pacing |
| 🛠️ **Stability** | Aim for a more consistent gameplay experience |
| 🌿 **Vanilla feel** | Keep the familiar Minecraft experience at the centre |
| 🤝 **Community** | Welcome useful bug reports, suggestions, and contributions |

*Actual performance depends on your hardware, Minecraft version, mod selection, drivers, and settings. No specific FPS result is guaranteed.*

2. Follow the installation instructions provided for that release.

4. Test the pack with your own hardware and settings.

## 🧪 Reporting a bug

Found a crash, visual issue, or performance regression? [Open an issue](https://github.com/AvronilHtech/Optimeta/issues) and include as much of this as you can:

- Minecraft version
- Mod loader and version
- Operating system
- CPU, GPU, and RAM
- Graphics settings and render distance
- Steps to reproduce the issue
- Relevant logs or crash reports, with personal information removed

Performance reports are especially helpful when they include both hardware details and settings.
